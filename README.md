# 📊 Simple Interest Calculator

A modern, interactive, and responsive web application designed to calculate simple interest earnings or loan payments effortlessly. Built with clean HTML5, modern CSS, and vanilla JavaScript, it features real-time dynamic updates, breakdown charts, and a detailed schedule table.

---

## ✨ Features

- **⚡ Real-Time Calculation:** Automatically updates interest and total balance as inputs change.
- **📊 Visual Data Breakdown:** Interactive donut/bar charts displaying the ratio of Principal vs. Earned Interest (powered by Chart.js).
- **📅 Year-by-Year Schedule:** Detailed breakdown table showing annual balance growth and interest accumulation.
- **➕ Additional Contributions (Optional):** Supports calculating periodic contributions (monthly/yearly) alongside base principal.
- **📱 Fully Responsive:** Clean, mobile-first design with smooth UI/UX across all device sizes.
- **🎨 Dark / Light Mode Support:** Automatic adaptation or toggle for user preference.

---

## 🧮 How Simple Interest Works

Simple interest is calculated using the standard formula:

$$A = P (1 + rt)$$

Where:
* **$P$** = Principal amount (Initial investment or loan amount)
* **$r$** = Annual interest rate (in decimal form, e.g., $5\% = 0.05$)
* **$t$** = Time duration (in years)
* **$A$** = Total accrued amount (Principal + Interest)

**Total Interest ($I$):**
$$I = P \times r \times t$$
